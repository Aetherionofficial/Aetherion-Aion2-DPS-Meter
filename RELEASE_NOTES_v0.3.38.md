# Aetherion DPS Meter v0.3.38 — Fenster-Hotfix

## Meter-Design

- Das Kampf-Overlay ist wieder kompakt wie in der ersten veröffentlichten Version: schmale Schadensbalken, klare Zahlen und das ursprüngliche Dunkel-Gold-Farbschema.

## Updates

- Aetherion prüft kurz nach dem Start auf neue Versionen und öffnet bei einem verfügbaren Update direkt das Update-Fenster.
- Bereits im Hintergrund geladene Installer werden beim Klick auf „Jetzt aktualisieren“ direkt verwendet.

## Raid Command

- Das Raid-Command-Fenster lässt sich jetzt am gesamten freien Kopfbereich ziehen.
- Das Kampfzentrum startet zentriert und kleiner, sodass mehr vom Spiel sichtbar bleibt.
- Die Fenstergröße kann weiterhin über die Kanten angepasst werden.
