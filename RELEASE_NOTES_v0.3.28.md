# Aetherion DPS Meter v0.3.28

## Deutsch — Übersichtliche Kampfauswertung
- **Mehr Platz:** Die Kampfauswertung öffnet größer und bietet Skillnamen sowie Tabellenwerten mehr Raum.
- **Vollständige Namen:** Abgeschnittene Kampf- und Spielernamen lassen sich per Tooltip vollständig ansehen.
- **DPS-Verlauf:** Die ersten Sekunden zeigen eine feinere Zeitachse und auch einzelne Messpunkte.
- **Heilung klar dargestellt:** Wenn keine Heilung erfasst wurde, zeigen Highlights und Heilungsseite einen erklärenden Hinweis statt einer irreführenden Null.

## English — Clearer fight breakdown
- **More room:** The breakdown opens larger, giving skill names and table values more space.
- **Full names:** Hover over truncated fight or player names to see the complete name.
- **DPS timeline:** The first seconds use a finer time scale and display individual samples.
- **Clear healing state:** When no healing was recorded, highlights and the healing page show an explanation instead of a misleading zero.

## Hinweise / Notes
- Npcap is required for live combat capture. Microsoft Edge WebView2 Runtime is required for the embedded map.
- Ein aktiver Aetherion-Zugang ist erforderlich. Support: [Discord](https://discord.gg/mostwantedde).
