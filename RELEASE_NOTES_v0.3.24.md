# Aetherion 0.3.24

## Deutsch
- Der portable Updater versucht jetzt bis zu 30 Sekunden erneut, eine noch gesperrte Programmdatei zu ersetzen.
- Bei einem fehlgeschlagenen Update bleibt das heruntergeladene ZIP erhalten und Aetherion versucht, die bisherige App wieder zu öffnen.
- Nach erfolgreichem Austausch wird die aktualisierte App automatisch gestartet.

## English
- The portable updater now retries replacing the app file for up to 30 seconds if Windows still has it locked.
- If an update fails, the downloaded ZIP is kept and Aetherion attempts to reopen the existing app.
- After a successful update, the updated app starts automatically.
