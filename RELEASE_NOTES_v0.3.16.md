## Aetherion DPS Meter v0.3.16

### Deutsch
- Lizenzzugriff wird jetzt pro Discord-Konto an die erste Installation gebunden.
- Ein Zugriff desselben Kontos von einer anderen Installation sperrt den Zugang automatisch und beendet den Meter.
- Die Prüfung läuft beim Anmelden und während die Anwendung geöffnet ist.
- Bereits eingelöste Lizenz-Keys bleiben einmalig und an das Discord-Konto gebunden.

### English
- License access is now bound to the first installation for each Discord account.
- Access from another installation automatically revokes the entitlement and closes the meter.
- The check runs at sign-in and while the application is open.
- Redeemed license keys remain single-use and tied to the Discord account.

### Hinweis
Das Update benötigt die mitgelieferte Supabase-Migration und Edge Function. Bitte erst verteilen, wenn beides im Supabase-Projekt erfolgreich veröffentlicht wurde.
