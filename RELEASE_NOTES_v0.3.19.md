# Aetherion DPS Meter v0.3.19

### Deutsch
- Vorübergehende Verbindungsprobleme bei der Lizenzprüfung führen nicht mehr zu einer falschen Zugangssperre.
- ZIP-Updates starten die aktualisierte App nach dem Ersetzen der Dateien automatisch erneut; der Neustart wird bei einem kurzen Windows-Dateizugriff erneut versucht.

### English
- Temporary connection failures during license checks no longer cause a false access lockout.
- ZIP updates automatically restart the updated app after replacing its files, retrying briefly if Windows is still releasing a file.
