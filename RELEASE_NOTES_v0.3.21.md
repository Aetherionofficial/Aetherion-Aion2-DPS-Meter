# Aetherion DPS Meter v0.3.21

## Deutsch
- GitHub-Repository- und Updateverweise verwenden jetzt den Aetherion-Organisationspfad.
- Lizenz-Sperrlisten werden vom Aetherion-Repository geladen.

## English
- GitHub repository and update links now use the Aetherion organization path.
- License revocation lists are loaded from the Aetherion repository.

## Voraussetzungen
Npcap wird für die Live-Kampferfassung benötigt. Microsoft Edge WebView2 Runtime wird für die eingebettete Karte benötigt.

## Requirements
Npcap is required for live combat capture. Microsoft Edge WebView2 Runtime is required for the embedded map.
