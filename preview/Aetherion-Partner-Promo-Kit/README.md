# Aetherion Partner Promo Kit

Fertige Partner-Grafiken für die Beispielaktion „15 % sparen mit NOVAZ15“.

- `partner-banner.svg` – Twitch-Panel, Website oder Discord
- `stream-promo-strip.svg` – schmale Grafik für den Streamrand
- `social-promo-square.svg` – quadratischer Social-Post/Discord
- `Partner-Textvorlage.txt` – direkt kopierbarer Partner-Post
- `Partner-Promo-Preview.html` – Vorschau der Grafiken

## Einlösen

Die Website führt Kaufanfragen aktuell über Discord-Tickets; es gibt keinen automatischen Checkout, der den Code selbst abzieht. Kunden müssen `NOVAZ15` vor der Zahlung im Ticket nennen. Die zuständige Person muss den 15-%-Rabatt im Ticket manuell bestätigen und den reduzierten Zahlbetrag mitteilen. Die Grafiken allein aktivieren keinen Preisnachlass.

Code und Prozentwert in den SVG-Dateien ändern, wenn ein anderer Partner einen eigenen Code erhält.
