# Aetherion DPS Meter v0.3.32

## Deutsch
- **Overlay-Lesbarkeit:** Spielerzeilen halten Gear-Infos und Klassenbalken sauber auseinander.
- **Deckkraft:** Neue und migrierte Installationen starten mit klar lesbarem, stärker abgedunkeltem Hintergrund. Die Deckkraft lässt sich weiterhin anpassen.
- **Kompakte Größe:** Das Overlay startet kompakter und lässt sich bis auf 320 × 260 verkleinern.

## English
- **Overlay readability:** Player rows keep gear details and class bars separated.
- **Opacity:** New and upgraded installations start with a clearer, darker background. Opacity remains adjustable.
- **Compact sizing:** The overlay starts more compact and can be resized down to 320 × 260.
